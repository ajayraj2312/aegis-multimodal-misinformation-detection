Reading these numbers honestly

Every value on this page is computed by src/evaluate.py on a held-out test split that no model saw during training or threshold selection. Nothing is hard-coded.

The benchmark is a proxy corpus: curated claim texts paired with procedurally rendered topic scenes. It is designed to be regenerable and inspectable, not to represent the full diversity of real-world misinformation. Accuracy on this benchmark therefore should not be read as expected real-world accuracy.

The image-only model is expected to be weak: a single image carries little information about whether the accompanying claim is true. Its usefulness in this architecture is as a consistency reference for the fusion layer, not as a standalone detector.

Reproduce with: python -m src.train then python -m src.evaluate.
